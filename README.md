# lasha.digital – Portfolio

Meine persönliche Portfolio-Website, komplett selbst gestaltet und entwickelt.

**Live:** https://lasha.digital/

## Tech
- HTML, CSS, Vanilla JavaScript
- GSAP inkl. ScrollTrigger für Animationen
- Lenis für Smooth Scrolling

## Highlights
- Eigene Scroll-Animationen mit GSAP ScrollTrigger
- Vollständig responsiv, ohne Framework
- Dynamisches Akkordeon in Vanilla JS, ohne zusätzliche Library
- Interaktive Elemente, die auf Mausbewegung reagieren
